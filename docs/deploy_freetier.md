# 免费部署方案调研（2026-09-19）

> **背景**：项目要「让别人能点开链接」，但当前预算为 0。本文整理 2026 年真实可用的免费方案，
> 并按本项目（FastAPI + WebSocket + 写文件 + 国内面试官访问）的实际需求做适配度评估。
> **免费政策变化极快**（Heroku 2022 关免费档、Railway 取消永久免费），本文数字以 2026-09 调研为准，
> 用它之前请复核一遍官方定价页。

---

## 一、先确定需求（否则选型无从谈起）

| 需求 | 来源 | 硬约束级别 |
|------|------|-----------|
| **常驻进程，单次请求可跑 10~30s** | 通勤矩阵按 0.35s 限频逐个查高德 + 求解 1.5s + LLM 抽取 2.7s | **硬**（Serverless 10s 超时直接判死） |
| **WebSocket 长连接** | `/ws/{task_id}` 阶段进度推送 | **硬**（Serverless 不保持长连接） |
| **可写文件系统** | `data/plans/*.json` 历史规划 + 三个 `.xxx_cache.json` 缓存 | **硬**（只读文件系统会让历史保存失败） |
| **国内访问速度** | 简历链接给国内面试官/HR 点开 | **硬**（境外节点慢或被墙 = 链接白给） |
| 内存 | 实测见下 | 中（256MB 起够） |
| 不休眠 | 面试官随时点开 | 中（休眠 + 冷启动伤第一印象） |

## 二、本项目实测资源占用（2026-09-19 本机实测，`tasklist` 读 Working Set）

| 场景 | 耗时 | 内存 |
|------|------|------|
| 服务空闲 | — | **52 MB** |
| 全缓存规划（5 景点 / 2 天，122 次缓存命中、0 次 API） | **0.0s** | 52 MB |
| LLM 攻略抽取 + 实体对齐（5 个景点） | **2.7s** | **峰值 100.6 MB / 驻留 102 MB** |

**结论**：**256MB 实例够用**（峰值 ~110MB，留 ~140MB 余量）；512MB 宽裕。
注意 `openai` 库是延迟导入的，所以不调 LLM 时会省下约 50MB——这也是空闲只有 52MB 的原因。

## 四、结论与推荐路径

**核心判断：免费方案里没有一个能同时满足「免信用卡 + 不休眠 + 有持久盘 + 国内快」。** 必须取舍。

**推荐路线（按优先级）：**

1. **应急演示 → 内网穿透（Cloudflare Tunnel 或 cpolar）**
   - 今天就能用，零成本，本机磁盘天然持久化，国内速度好。
   - 代价：**电脑必须开着**（笔记本合盖断网）。适合「提前开机 → 把链接发人 → 演示完关掉」的用法。
   - 注意：用 `trycloudflare` 临时域名每次重启会变；要固定地址需自备域名。

2. **长期免费主力 → Oracle Cloud Always Free**
   - 算力是免费方案里最强的（ARM 4 核 24GB，远超需求），真 VM，`docker-compose.yml` 可直接用。
   - 代价：需绑卡验证（不扣费）、要自己运维（安全组/防火墙/Docker/TLS）、**ARM 实例受容量限制可能开不出来**（开不出就换区域或等）。
   - 适合：愿意花 1~2 天折腾，换一个永久免费的独立服务器。

3. **不想折腾 → Fly.io**（有 3GB 持久卷、不休眠，但需绑卡）或 **国内学生机 8.9~9.9 元/月**（最省心）

**不推荐**：Render Free（冷启动 30~60s + 临时盘）、Vercel/Netlify/CF Workers（架构不匹配）、Railway（已无永久免费档）。

## 五、无论选哪个都必须先做的事（与平台无关）

1. **配额保护**：公网 = 任何人可调用。不设限，高德与 DeepSeek 的 key 会被扫到刷爆。
   最低要求：每 IP 每日规划次数上限 + 单次规划规模上限（景点数/天数）。
2. **key 只放平台环境变量**，不进镜像、不进仓库（`.env` 已在 `.gitignore`）。
3. **高德控制台给 key 设日调用量上限**——这是平台侧的硬止损，比代码限流更根本。
4. **异常兜底**：`/extract` 目前只 catch `RuntimeError/ValueError/KeyError`，而 `reliability.retry_call`
   重试用尽后抛的是**原始异常**（`APITimeoutError` 等）→ 会穿透成 HTTP 500。部署前需统一兜底。
